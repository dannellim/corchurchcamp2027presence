# COR Church Camp 2027 · Presence

Save-the-date website for **COR Church Camp 2027** by Chapel of the Resurrection, organised by the El-Pizo cell group.

- **When:** Saturday 29 – Monday 31 May 2027 (3 days, 2 nights)
- **Where:** Four Points by Sheraton Desaru, Bandar Penawar, Johor, Malaysia

**Live site:** https://dannellim.github.io/corchurchcamp2027presence/

## Updating the site

Edit `index.html` and push to `main`. GitHub Pages republishes automatically within a minute or two.
